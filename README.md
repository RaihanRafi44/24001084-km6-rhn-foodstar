# FoodStar

## Overview

**FoodStar** is a Android app for food ordering with authentication and order management features.

## Features

- **Homepage**: Displays the username, banner, menu categories, and available food and beverage menus. Users can browse the available menus.
- **Sign In**: Users can log in to their accounts.
- **Sign Up**: New users can create an account.
- **Reset Password**: Users can reset their password if they forget it.
- **Cart**: Users can view menu items that have been added to their cart. Users can also change the order quantity and add notes to each menu item they order.
- **Menu Detail**: Users can view menu details, including descriptions and store locations. They can also order items from here.
- **Checkout**: Users can view orders, along with notes and correct order quantities. They can select delivery and payment methods and view the total price. Here, users can also place orders and pay later via the checkout button.
- **Profile**: Users can update their profile data.

## Tech Stack

- Using Firebase for authentication and crashlytics
- Using Android XML for UI layout
- Using Material3 as the design system to build a modern and consistent user interface.
- Using Koin for dependency injection
- Using MVVM (Model, View, View Model) for design pattern
- Using Room for local database
- Using Retrofit to integrate REST API provided by Binar Academy
- Handling API responses and error states for data-driven UI

## Installation

To get started with FoodStar, follow these steps:

1. Clone the repository:
    ```bash
    git clone https://github.com/RaihanRafi44/24001084-km6-rhn-foodstar.git
    ```
2. Open the project in Android Studio.
3. Build and run the application on your Android device or emulator.

## Requirements

- Android Studio Iguana++
- Android Smartphone minimum version is 8.0 (Oreo)
- Internet connection

## Usage

1. Launch the application.
2. Sign in or create a new account.
3. Select the food or drink menu to be ordered along with the quantity you wish to order.
4. Select the delivery and payment method and check the order again to see whether it is correct or not.
5. After that, proceed to checkout. Don't forget to make sure your shopping cart is empty after checkout.
